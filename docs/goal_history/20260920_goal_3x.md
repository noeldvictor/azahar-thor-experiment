# Goal set 2026-09-20: full speed at 3x with GSR

Replaces the 2026-09-19 goal, which was written against 2x. Kept at
`20260920_goal_2x_superseded.md` with its full outcome and the list of everything ruled out.

## Why the target moved

The Thor's main panel is 1920x1080 and the emulator draws the 3DS top screen at 1800x1080 inside
it. The top screen is 400x240, so native 1:1 for this panel is 4.5x. At 2x the picture is upscaled
2.25 times and is visibly soft, which the user confirmed by eye before the measurement was taken.
So 2x was the one resolution that cannot look right on this hardware, and a goal written against
it optimised for a picture nobody should be looking at.

Snapdragon Game Super Resolution, `screen_filter = 2`, is free: 64.10% against 63.73% without it
at 3x. It runs once on the final present, which is nothing against 31 million shaded fragments.

## The goal

E.X. Troopers, measured only in the snow field from save state 5, holds Speed 100% or better at
60 FPS at resolution 3x with the frame limit at 100 and `screen_filter = 2`.

Everything else follows the procedure of the superseded goal: at least five `perf_stats` samples
beside a screenshot of the snow scene from the same run, no reading from a menu, title screen,
cutscene or video, and a run whose GPU clock fell below 615 MHz is void. Check `thermals` as well
as the GPU clock, because a CPU cap can drop while the GPU clock still looks correct.

## Where it stands at the moment the goal was set

| setting | speed | note |
| --- | --- | --- |
| 2x + GSR, limit 100 | 100.03% | full speed, sharper than plain 2x |
| 3x + GSR, limit 100 | 64.10% | the target; needs a 36% cut in frame time |
| 4x, limit 100 | 41.46% | near native on this panel; the stretch goal |

3x needs the frame from 26.05 ms to 16.67 ms.

## What is already ruled out

Read the table in `20260920_goal_2x_superseded.md` before proposing anything. Twenty-two
candidates are closed with numbers, including fragment ALU at 13% of the frame, tiling at every
resolution, every Turnip debug flag, occupancy, the GPU clock, and the whole CPU paradigm sweep.
The frame is 30 full screen passes with about 2.6 times overdraw each, and the pass count is what
blocks tiling: a pass costs 25.2 us tiled against 5.4 us direct.
