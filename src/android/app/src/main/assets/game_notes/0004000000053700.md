E.X. TROOPERS  (Japan, English patch shares this title id)

RECOMMENDED
  Resolution 2x, Screen Filter Snapdragon GSR, frame limit 100.
  That is what the bundled profile sets and it holds full speed with the
  picture correct everywhere in the game.

MEASURED ON THE AYN THOR  (snow field, save state 5, GPU at 680 MHz)
  2x + GSR    99.97% mean, 99.87% min, 59.74 FPS, 13.21 ms frame
  3x + GSR    63.79%
  4x          39.07%
  2x, limit 200   118%   (not 200%: that row is CPU bound, not GPU)

WHY IT IS HEAVY
  The snow field submits about 1800 alpha blended draws a frame at roughly
  58x overdraw. That is the blizzard, drawn as geometry rather than as an
  effects pass. Resolution scaling multiplies all of it, so 3x costs nine
  times as much as 1x. For comparison, Ocarina of Time 3D reads 1213% at 3x.
  Nothing here is emulator overhead: draws are one to one with the guest,
  100% hardware accelerated, and it is not rendering two stereo eyes.

FRAME RATE
  This game is already 60 FPS. Its videos present at 30. The 60 FPS cheat
  codes are a target override, not an unlock, so the useful direction on a
  handheld is the 30 FPS code when a scene needs headroom.

DRAW RULES  (ShaderRules/0004000000053700.txt)
  Ships commented out. Enabling them takes the snow field to 99.66% at 3x
  and keeps the blizzard, lighting and outlines, but elsewhere in the game
  they remove weapon icons from the HUD, stop some text drawing and leave a
  checkerboard through surfaces that should blend. A shader fingerprint
  identifies a shader, not a purpose. Enable only if you check your scenes.

CHEATS
  The English patch and the Japanese release share a title id but not their
  addresses. Use only the entries suffixed for the build you are running.

KNOWN ISSUES
  Opening the pause menu during a video can stall the present path. The AYN
  dual screen assistant taking focus does the same; emulation keeps running
  underneath, so it looks frozen but is not.
